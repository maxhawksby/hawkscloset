# Launch plan: Friday, October 16, 2026, 12:00 noon New York

Max's call (2026-09-28): premium buyers get in early with the store password, and Max removes the password by hand when the drop opens to everyone.

## How it works
1. **Before the drop:** the store stays password-protected. The password page shows the countdown to noon and the "Early access" password box.
2. **Early access:** Max sends premium buyers the store password. They enter it on the password page and shop the new pieces before everyone else. The new pieces must be **Active** (published) for them to see them.
3. **At noon:** Max turns the password off in Shopify admin (Online Store > Preferences > Password protection). The gallery is open to everyone.

## Checklist
Before launch week:
- [ ] Max loads the 15-20 new pieces (flat lays), in a collection for the home wall (for example "Now showing"). Descriptions start with the measurements, e.g. `23/30 | tagged XL`, so the site can show "XL | 23/30".
- [ ] Max clicks through the pushed gallery theme on Shopify (unpublished) on phone and laptop.
- [ ] Theme settings on that theme: home wall collection, Klaviyo keys, launch videos when they arrive.
- [ ] Create the About page in Shopify with the template `page.about`.

Before early access opens (Max approves each step):
- [ ] Publish the gallery theme. The password page is part of it, so the countdown and Early access box stay in front of the shop.
- [ ] New pieces set to Active.
- [ ] In a private window: the password page shows; entering the password opens the gallery with the new pieces.
- [ ] Send the password to premium buyers.

At noon on October 16:
- [ ] Turn off password protection.
- [ ] Private window: the gallery opens without a password; add a piece to the cart and reach checkout.

## Also available
The theme has an optional launch screen (Theme settings > Launch > "Show the launch screen until the launch time") that covers every page with the countdown and opens by itself at the launch time. It is off, and not needed for this plan. It would only matter for a future drop without a password, together with Shopify's scheduled publishing.
